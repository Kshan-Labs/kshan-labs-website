# Learning by Building

## Thoughts / 001

I've been realizing that the best way for me to learn technology is to actually build something.

It's easy to spend hours watching tutorials and reading documentation. But when I try to create something myself, I have to understand how the different pieces connect.

## What I'm learning

Building KSHAN Labs has already taught me things I probably wouldn't have understood by only studying them.

I've worked with React, Vite, CSS, Git, GitHub, Linux, and GitHub Pages while creating the site itself.

## A thought

I don't think I need to know everything before starting.

I can start with something small, make mistakes, figure things out, and improve it along the way.

That's what I want KSHAN Labs to be about.

> Learn by building. Document the process. Keep evolving.
